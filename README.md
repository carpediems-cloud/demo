# Demo

A collection of learning projects and practice programs organized by stack.

## Folder Layout

- `web/` - Browser-based projects and UI experiments.
- `web/react-page/` - Vite React project.
- `python/` - Python scripts and small terminal projects.
- `java/` - Java practice programs.
- `javascript/` - Standalone JavaScript examples.
- `notes/` - Plain text notes and references.

## Running Projects

Most folders contain standalone files that can be opened or run directly:

- Open HTML demos from their `web/<project>/index.html` file.
- Run Python scripts with `python <script-name>.py` from the `python/` folder.
- Compile Java programs from the `java/` folder with `javac`.
- For the React app, run `npm install` and `npm run dev` inside `web/react-page/`.

Generated files such as Java `.class` files, dependency folders, and build output are ignored.
