# Balloon Pop Parade

A colorful balloon pop mini project for children made with HTML, CSS, and JavaScript.

## How to run

Open `index.html` in your browser.

## How to play

- Press `Start Game`.
- Click the floating balloons to pop them.
- Earn points and collect stars before the 30-second timer ends.

## Files

- `index.html` for the page layout
- `styles.css` for the bright kid-friendly design
- `script.js` for the balloon movement and pop game logic
